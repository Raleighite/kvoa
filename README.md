# KVOA — YouTube Analytics Visualizer

Data visualization project using Bokeh for YouTube channel analytics.

## Contents

- `src/youtube.py` — YouTube Data API client
- `src/models.py` — Data models
- `src/bokeh-test.py` — Bokeh chart experiments
- `src/lines.html` — Generated Bokeh output

## Setup

```bash
pip install -r requirements.txt
```

Requires a YouTube Data API key set in your environment.
